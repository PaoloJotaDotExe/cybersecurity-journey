# OverTheWire — Bandit

[Bandit](https://overthewire.org/wargames/bandit/) is a beginner wargame that teaches Linux and command-line fundamentals over SSH.

Connect: `ssh banditN@bandit.labs.overthewire.org -p 2220`

## Levels

| Level | Key concept | Writeup |
|---|---|---|
| 0 → 1 | Reading a file in the home directory | [level-00.md](level-00.md) |
| 1 → 2 | File named `-` (dash) | _to do_ |
| 2 → 3 | File name with spaces | _to do_ |
| 3 → 4 | Hidden files | _to do_ |
| 4 → 5 | Finding the only human-readable file | _to do_ |
| 5 → 6 | `find` with size and permission filters | _in progress_ |

## Writeup template

Copy this into `level-XX.md` for each new level:

```markdown
# Bandit Level X → Y

## Goal
What the level asks for, in my own words.

## What I tried
Commands I ran, including the ones that did not work, and why.

## Solution
    command here

## What I learned
One or two concepts I will reuse later.
```
